# Семейный финплан

https://ekerimkhanova.github.io/family-finplan/

План семейного бюджета на год: доходы, обязательные расходы, свободные деньги и цели.
Показывает, на что хватит денег в этом году, что переносится на следующий и сколько откладывать на каждую цель каждый месяц.
Умеет выгружать отчёт в PDF и Excel.

Всё приложение — один файл `index.html`, без сборки и зависимостей.
Данные хранятся только в браузере (localStorage) и никуда не отправляются.
